# Features (by priority tier)

## Tier 0 — MVP must-haves

Without these, the product doesn't function.

- [ ] Magic-link authentication (no passwords)
- [ ] Create a pet profile (name, species, breed, DOB, photo)
- [ ] Unique ingestion email address per pet
- [ ] Inbound email webhook + raw storage
- [ ] Claude-powered email classification and extraction
- [ ] Pet page with timeline, photos, records sections
- [ ] Basic records views (vaccinations, meds, vet visits, bills)
- [ ] Shareable public view of the pet page (no login required)

## Tier 1 — Hero features (the reason to pay)

- [ ] **AI vet visit prep summary** with shareable link for vet
- [ ] **Monthly digest email** with the month's photos and moments
- [ ] **Year-in-review generation** on pet's birthday or adoption anniversary
- [ ] **"A year ago today" memories** for notable logged events
- [ ] **SMS interaction** — inbound texting for quick logs and photos
- [ ] **SMS reminders** — outbound reminders for preventatives, vaccinations, appointments
- [ ] **Multi-pet support**

## Tier 2 — Power features (nice retention boosters)

- [ ] AI anomaly detection from logged data (weight trends, activity changes, eating patterns)
- [ ] Expense tracking dashboard and yearly totals
- [ ] Shareable sitter-mode view with care instructions and emergency info
- [ ] Emergency QR code sticker for collar
- [ ] Lost pet poster generation
- [ ] Multi-user collaboration (spouses, family members adding to the same pet)
- [ ] Export to PDF for insurance claims or vet changes

## Tier 3 — Platform and integrations

- [ ] **Wearable integration: FitBark API** (easiest third-party, good proof of concept)
- [ ] **Wearable integration: Tractive API** (if accessible)
- [ ] **Partnership integration: Fi** (requires BD)
- [ ] **Photo integration: Apple iCloud Shared Albums / Google Photos** for auto-ingest of pet photos via face detection
- [ ] **Pet insurance API integrations** — Lemonade, Trupanion, Embrace, Figo
- [ ] **Vet practice software integrations** — the holy grail, likely years out (Covetrus, IDEXX, Cornerstone, AVImark)

## Tier 4 — Wild / far future

- [ ] AI pet Q&A ("is this normal for a 4yo golden?")
- [ ] Photo-based symptom analysis (upload rash photo, get "probably nothing, but watch for X")
- [ ] Telemedicine integration
- [ ] Custom hardware collar (see [[10-hardware-vision]])
- [ ] Multi-template platform (events, projects, handoffs, collections)
- [ ] White-label version for high-end vet clinics

## What's explicitly NOT in scope

- Pet social networking
- Marketplace / e-commerce
- Pet insurance underwriting
- Clinical records for vet practice internal use
- Behavior training curriculum
- Adoption / fostering listings
- Pet food subscriptions (though we could eventually link out)
