The recipe, in one line

It wasn’t that the AI got smarter. Seven boring things stacked up: background orchestration + a real test signal + a headless toolchain (esp. xcodegen) + adversarial review + planning scaffolding + permissive execution + durable git-commit state — with a human checkpoint at each phase boundary. The one-liner: the test signal is the product. Background orchestration is impressive and multi-agent review is clever, but the thing that turns “AI wrote some code” into “an app that runs on my phone” is that every step had to prove itself against a build that either passed or didn’t. Then go re-run the tests yourself. Always.
