# Homepage

**A homepage for your pet.**

Forward vet bills, vaccination records, photos, and notes to your pet's own email and text number. The AI organizes everything into a beautiful living page, sends proactive reminders, and generates vet visit prep summaries on demand.

Every pet gets their own URL: `<petname>.homepage.pet`

## Domain

- Primary: **`homepage.pet`** (acquired)
- Pet pages: `sandy.homepage.pet`, `max.homepage.pet`, etc. (subdomain per pet)

## Structure

- `docs/` — Obsidian vault with all planning, research, and design notes. Open this folder in Obsidian to browse as a linked knowledge base.
- (future) app code will live at the root of this folder
